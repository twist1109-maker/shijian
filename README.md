# 书语 · 图书营销工作台

## 从 GitHub 下载

1. 点击仓库页面绿色 **Code → Download ZIP**，下载后**全部解压**。
2. PPT：`docs/书语营销系统_汇报PPT.pptx`；设计说明：`docs/需求与设计说明.docx`，可直接打开。
3. 安装 Python 3.10 或以上版本，双击根目录 `启动.bat` 运行项目。
4. 首次建议使用模拟模式演练；真实调用请在自己电脑配置密钥。

## Windows 快速启动
1. 安装 Python 3.10 或以上版本（建议3.12）。无需 pip 安装依赖。
2. 将项目解压到固定目录，双击“启动.bat”。保留黑色服务窗口。
3. 浏览器打开 http://127.0.0.1:8765 。仅本机访问。
4. 营销账号：editor / Editor123!；审核账号：reviewer / Review123!。

若双击失败：在项目目录打开终端，运行 `py -3 app.py`，手动打开上述网址。
端口占用：关闭旧服务窗口；或在终端设置 PORT 后运行，并使用对应端口网址。

## 配置真实模型（推荐在页面操作）
1. 用 editor 登录，点击左侧 **模型配置**（或顶部配置按钮）。
2. 选择 DeepSeek / OpenAI，填写对应模型名和 API Key。
3. 点击 **保存并测试连接**。页面会显示后端实际读取的服务商、模型、密钥来源和配置文件绝对路径；密钥本身不回显。
4. 测试会发送一条短请求，可能有少量服务商费用。连接成功后，再到任务中使用真实模型模式。

**不要只修改 config.example.json**：这是示例文件，不会生效。若已填在这里，复制为 config.local.json，并恢复示例文件中的占位符；不要上传密钥。
也可以把 config.example.json 复制为 config.local.json 后填写，保存后刷新页面即可，无需重启。
支持项目根目录 `.env` 和系统环境变量（无需额外安装库）：
```
MODEL_PROVIDER=deepseek
DEEPSEEK_API_KEY=你的本机密钥
MODEL_NAME=deepseek-chat
```
OpenAI可使用 OPENAI_API_KEY，默认模型为gpt-4o-mini；通用密钥变量为 MODEL_API_KEY。
同一字段优先级：非空系统环境变量 > .env > config.local.json。空环境变量不会覆盖文件值。若保存后仍由环境变量生效，页面会提示实际来源。
模型支持工具调用仍需实际任务验证，连接测试不能代替完整 Agent 验收。
不要使用 VS Code Live Server 或直接打开 static/index.html；请运行 `py -3 app.py` 并访问后端打印的地址。

## 更新到修复版 v1.1.0
停止旧服务（终端 Ctrl+C），在项目目录执行 `git pull`，再运行 `py -3 app.py`。
浏览器使用 Ctrl+F5 强制刷新，应显示v1.1.0和“模型配置”。不会删除现有data.db。
修复：成功后按钮不恢复、未保存草稿切换丢失、进程重启遗留运行中状态、配置错误导致状态接口或后台异常。
已增加后端图文导出接口，审核完成的任务也能导出；保存并提交会先保存未提交修改。

## 5分钟演示
1. 营销登录，新建任务，选择“把时间留给阅读”，填写读者与渠道。
2. 选择真实模型调用，点击生成。在执行依据查看真实工具名称、参数和返回结果。
3. 查看图文草稿与来源，修改一处文字并保存新版本，再提交审核。
4. 退出，换审核账号，在审核记录填写意见，退回修改。
5. 换营销账号修改保存、重新提交；审核账号通过，查看历史版本。
6. 另建任务，切换读者或渠道，展示结果变化。
7. 用“城市里的自然课”展示定价缺失：模型应注明待确认，不得编造。
8. 模拟超时故障仅用于确定性故障演练，不能冒充真实网络超时证据。

## 模拟模式与限制
模拟演练不需要密钥，后端真实执行本地读取和校验工具，但草稿是模板响应，不是大模型生成；界面和记录明确标识。
目前通过24项后端/业务检查；没有密钥，因此未验证真实服务商调用。浏览器交互、Windows启动、录屏仍需在目标电脑验证。
最终文案另外做后端校验，该条是确定性复核，并非模型自主选择。前面的模型工具调用记录才用于展示 Agent 行为。
教学封面为项目原创 SVG，并非图书真实封面；样例书目、作者、内容均为教学模拟。
工具校验只覆盖部分禁用词、数字依据和篇幅，不代表完整事实或法律审查。
资料为追加保存，更新时新增资料ID，旧资料不覆盖；当前版本固定v1，任务记录关联不可变资料。
单人可分别扮演两个业务角色；正式考核是否允许单人成组需要教师确认。

## 保存与交付
首次启动自动生成 data.db，包含账号、资料、任务、版本、运行和审核记录。
退出服务后复制 data.db 可备份演示数据。不要公开包含实际资料的数据库。
清空演示：关闭服务后备份并移走 data.db，下次启动会初始化。不要在运行中删除。
交付源码时排除 config.local.json、实际密钥和敏感数据库。
本项目仅用于本机教学演示，默认密码公开，不应直接作为公网生产系统。

### 快速验收
保持app.py运行，在另一个终端执行：
```powershell
py -3 scripts/acceptance.py
```
默认只做模拟流程。配置真实密钥后，可执行下面命令（会使用API额度）：
```powershell
py -3 scripts/acceptance.py --real
```
脚本生成正常/资料不足的任务与证据；故障分支是明确的模拟超时，不冒充真实网络失败。输出在本机evidence目录，已被git忽略。还需人工核对、Windows浏览器展示和备用录屏。
