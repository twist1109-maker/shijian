# 数据结构与来源（v1.2）

| 表 | 关键字段 | 作用 |
|---|---|---|
| users | name、role、salt、hash | 两个教学角色，PBKDF2密码哈希，不保存明文密码 |
| materials | id、title、content、source、version、cover_data、created | 不可变图书资料；追加导入获得新ID；封面可选 |
| tasks | id、owner、material_id、title、audience、channel、tone、length、status、ai_status、created | 任务需求、归属与独立状态 |
| versions | id、task_id、content、actor、created | 正文追加保存，至少两版本可查 |
| reviews | id、task_id、actor、action、comment、created | 提交、退回、通过记录 |
| runs | id、task_id、mode、status、error、snapshot、provider、model、created、finished | 单次运行及当次需求、内容SHA256、来源/规则版本 |
| logs | id、task_id、run_id、tool、args、result、status、created | 工具实际参数、返回、状态与错误 |

资料来源：samples中的书目、作者、目录和卖点均为本项目原创教学模拟信息，不代表真实出版物。无用户封面时按资料标题生成原创教学示意图；用户提供的封面须获准使用。

输入为表单或UTF-8 TXT/Markdown，不做OCR。资料版本保持v1且不可变；修改时新增资料ID，老任务继续关联原资料。snapshot中的SHA256对应资料正文，不是对封面真实性的鉴定。

脱敏导出：GET任务evidence输出需求、资料、规则、运行、工具记录、版本和审核意见；去除已知密钥及密钥字段。导出仍可能含用户业务信息，分享前需要本人核对。

历史记录说明：根目录docs中的“模拟运行记录_非真实模型.json”和“后端检查结果.json”为初版归档；最新v1.2模拟HTTP验收记录在“示例运行记录”中。所有模拟记录均不能代替真实服务商调用。
