## 验收前仍必须在本人Windows上完成
1. git pull并重启，确认页面版本1.2.0。
2. 配置DeepSeek或OpenAI，测试连接；运行两类真实工具任务并核对生成内容。此环境未持有本人密钥，没有宣称真实服务商验证完成。
3. `py -3 scripts/acceptance.py --real`生成正常、资料不足场景及模拟故障证据，保存到本地evidence目录。脚本会发起付费API调用，故障分支明确为模拟，不得称作真实网络失败。
4. 如果现场要求真实失败记录，保存实际发生的工具/服务商失败记录，不能用模拟记录冒充。允许受控工具参数错误演示；不要破坏已有人工版本。
5. 按5分钟讲稿录制完整浏览器备用视频，展示切换输入、来源、退回、两版本和后端越权拒绝。
6. 最新日期、单人分组资格、个人实习日记和报告模板由教师确认。个人经历不得代编。

## 当前验证边界
后端/配置/业务测试和前端事件处理器测试在Linux执行。前端事件测试使用DOM/HTTP替身；不是完整浏览器或Windows实测。当前环境缺少Sites流程指定的cua_repl浏览器工具，未生成浏览器录屏或截图。
固定图文模板不是AI生图；规则检查不是完整法律审查。封面只做类型、大小与文件签名初筛，不做内容真实性鉴定。
